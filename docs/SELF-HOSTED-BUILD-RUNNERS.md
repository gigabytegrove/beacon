# Archived — GitHub Actions is not part of Beacon builds

This document previously described self-hosted GitHub Actions runners. Those instructions are superseded: **all Beacon GitHub Actions workflows have been removed**.

No GitHub-hosted or self-hosted Actions runner is required or authorized for Beacon's build process. Builds must be performed directly on local development machines, verified, and then committed or uploaded as finished artifacts.

See [Local-only build policy](LOCAL-ONLY-BUILD-POLICY.md).
